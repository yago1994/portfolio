Broom

Privacy Policy

Last updated: May 12, 2026

The short version

Broom does not collect, transmit, sell, or share any personal data. Everything you do in the extension stays on your device.

What Broom stores

When you sweep an element or plant a garden, Broom saves the rule (a CSS selector and the change to apply) in your browser's local extension storage. This data:

  • Lives only on the device where you created it.
  • Is never synced, uploaded, or sent to any server.
  • Can be wiped at any time by removing the extension or clearing its storage.

Network requests

The extension makes a single network request, to yagoarconada.com/apps/broom_files/app-update.json, to check whether a newer version of Broom is available. The request contains no personal data beyond what your browser sends with any HTTP request (e.g. IP address, user-agent). Server logs are not analyzed or retained beyond standard web server defaults.

Page content

Broom reads the structure of the page you are editing in order to build a CSS selector for the element you point at. Page content is processed locally and is never transmitted off your device.

Permissions

  • storage — to save your rules locally.
  • activeTab — so the popup can talk to the tab you explicitly open it on.
  • Host access (<all_urls>) — so your saved rules can be reapplied on whichever sites you choose to use Broom on. No page content leaves your device.

Third parties

Broom does not use analytics, advertising, or third-party trackers. There are no third-party scripts in the extension.

Children

Broom does not knowingly collect any data from anyone, including children under 13.

Changes

If this policy ever changes, the updated date at the top of this page will change with it. Past versions are visible in this site's git history.

Contact
